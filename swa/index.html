Skills install endpoint

This host serves install redirects for github-copilot-agent-skills.

GET /i/{bundle} records an install and redirects to the download.

npx @thomast1906/skills add architect

No telemetry runs on your machine. The count is a server-side property of the redirect. To skip it entirely, use --from-github, or download directly from the repository.

Aggregate counts are public at /api/stats.
